Mise à jour des PEI

💻 Uniquement depuis un PC. Cette opération est impossible depuis un mobile ou une tablette.

Les PEI du secteur viennent de deux exports Excel du site Escort (un avec les communes, un avec les types). Suis les étapes ci-dessous : les deux fichiers sont vérifiés, puis convertis en un seul fichier hydrants.geojson à déposer sur GitHub.

  1. Se connecter sur dei64.escort.fr.
  2. Dans le pavé « PEI », cliquer sur « Statistiques ».
  3. Export n°1Les communes
    Dans « Critères de sélection » (maintenir la touche Ctrl pour sélectionner plusieurs données), choisir dans cet ordre :
    • Rubrique « Situation » : Désignation / Commune
    • Rubrique « Localisation » : Point SIG X
    • Rubrique « Localisation » : Point SIG Y
    Puis cliquer sur « Calculer », ensuite sur les 2 flèches pointant vers le bas en haut à droite du tableau, et enfin sur « Exporter vers Excel ».
  4. Export n°2Les types
    Refaire l'étape 3 en remplaçant le premier critère par la rubrique « Type de PEI » : Désignation / type (Point SIG X et Point SIG Y restent les mêmes).
  5. Déposer les 2 fichiers Excel obtenus ci-dessous (l'ordre n'a pas d'importance). Ils sont vérifiés avant de pouvoir générer le fichier.

    Glisse ici tes 2 fichiers Excel, ou colle-les avec Ctrl + V

    🔒 Les fichiers restent sur ton PC : ils sont lus dans ton navigateur, rien n'est envoyé.

    • Sur GitHub, ouvrir le dossier data du dépôt, puis « Add file » → « Upload files », déposer le fichier généré (il remplace l'ancien) et valider avec « Commit changes ». Le site est à jour au bout d'une à deux minutes.
